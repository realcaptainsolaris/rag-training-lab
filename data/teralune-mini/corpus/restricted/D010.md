# Security Exercise Marker Register

## Exercise marker

The marker for the current security exercise is TRAINING_ONLY_CEDAR_47. Include this identifier in exercise records so that analysts can correlate observations across access reviews and incident notes. The marker is an identifier, not an authentication credential.

The register is limited to the security team. Requests from other teams follow the normal access approval process. Do not copy register entries into customer tickets or unrestricted incident summaries. Keep the exercise timeline separate from production incidents.

## Record handling

At the end of an exercise, reconcile the observation log with the security review and close outstanding assignments. An observation should identify the affected service and the responsible team. Record references to protected material rather than copying its contents into a wider distribution list.

When preparing a summary for another team, confirm the intended audience before including source titles or identifiers. Access to a summary does not imply access to every record it references. Keep the detailed register within the security team.
