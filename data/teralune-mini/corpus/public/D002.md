# OAuth and API Keys

## Machine credentials

Orbit supports OAuth2 client_credentials for service accounts and scoped API keys for small integrations. Obtain an access token at /oauth/token. An Orbit 3.0 access token lasts 60 minutes. API keys expire after 180 days; they are not refresh tokens and cannot extend an OAuth session.

Choose a service account for a process, not a shared human login. Store its credential in the deployment secret store and inject it at runtime. A key label should describe its owner and purpose, for example lab-reader. The label is not an authorization rule. Deleting a label in a local configuration file does not revoke the corresponding key on the platform.

## Claims and scopes

The issuer is https://identity.teralune.example, the audience is orbit-api, and the accepted clock skew is 30 seconds. Reading measurements requires telemetry:read; submitting them requires telemetry:write. A valid signature alone does not authorize an operation. The service also checks expiry, audience, workspace and scope.

```http
POST /oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=lab-reader&client_secret=<TRAINING_SECRET>
```

The placeholder is intentionally unusable. Cache the returned token until shortly before expiry and replace it atomically so concurrent requests do not keep an expired token alive. Do not log the token body when diagnosing a claim error.

## Rotation without interruption

Create the replacement credential with the minimum scopes required by the integration. Deploy it to a single sender, confirm a successful read or write, then roll out to the remaining senders. Revoke the old credential after confirming that it is no longer used. A successful read is insufficient proof that a writer has the correct permissions.

If an integration fails only after rotation, inspect the workspace and scope before changing retry settings. Blind retries with an invalid credential increase noise and cannot restore access. Use the error identifier rather than the HTTP status alone when opening a support case.
