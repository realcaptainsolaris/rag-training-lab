Authentication Error Catalogue

Error identifiers

AUTH-104 means access token expired. AUTH-140 means required scope missing. AUTH-141 means workspace mismatch. The similar identifiers describe different decisions. Reissuing an otherwise identical token can resolve expiry but cannot add a missing scope or move the credential to another workspace.

Use the request identifier when reporting an error. The numeric suffix is not a severity score and must not be compared numerically. A user interface that displays only authentication failed discards the distinction needed to repair the request.

Other failures

RATE-201 means workspace request budget exhausted. HOOK-310 means delivery deadline exceeded. DATA-422 means measurement timestamp outside retention window. An HTTP status is a broad category; the Orbit identifier names the product rule that failed. A request with an expired token can be rejected before any measurement validation occurs. Fixing one error can reveal a different validation error on the next attempt.

Do not retry every 4xx response with the same payload. Record the identifier, workspace and timestamp, remove credentials from the log, and select a repair appropriate to the failed rule.
