# Webhook Delivery in Orbit 2.4

## Previous delivery window

This archived contract applies to Orbit 2.4. Retryable webhook deliveries continue for 24 hours. Do not apply this deadline to Orbit 3.0. The API prefix for this generation is /api/v2. The archive is retained so maintainers can reproduce behavior of installations that have not migrated.

When reviewing an old incident, identify the deployed product generation before comparing a delivery age to the deadline. A support ticket opened recently can still describe an older installation. The date of the ticket is not evidence that the sender runs the current version. Record the deployed generation in the incident timeline.

## Legacy service accounts

The access-token lifetime in Orbit 2.4 is 120 minutes. A new client that assumes the same lifetime in Orbit 3.0 may continue using an expired token. Prefer reading the token response lifetime to embedding the historical value in application code.

Archive copies are not change announcements. Use the migration guide when planning a cutover and use this contract only when the target installation is explicitly Orbit 2.4. Do not silently redirect a versioned API client to a different prefix.
