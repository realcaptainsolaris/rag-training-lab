# Deprecated integrations

## Connector transition notice

The Orbit 2.4 connector orbit-push reaches the end of its transition period on 2026-12-31. Orbit 3.0 deployments use orbit-stream. This notice applies to the old connector and does not redefine the authentication contract of the service.

Inventory the connector package and its actual target prefix before a migration. A process called orbit-stream that still points at an archived service is not necessarily running the current contract. Preserve the effective configuration in the deployment inventory.

## Archived worker note

The deployment note retained with the old connector says that OAuth tokens last 120 minutes and the workspace budget is 500 requests per minute. These settings describe its 2.4 target. A later package installation does not make these settings a current 3.0 reference.

Before changing cache timers, obtain the target version from the service configuration. Keep the archived note with the previous deployment so maintainers can reconstruct an incident. Do not replace it in place with current settings and erase the history.

## Review before replacement

Move one integration first and compare accepted observations and receiver actions. A total request counter can rise because the new connector retries differently even when the number of unique actions remains unchanged.

After a successful cutover, disable the old connector scheduler before retiring its credential. Two independent schedulers reading the same source can submit the same physical reading through different client paths. The resulting duplicates cannot be diagnosed from a credential label alone.
