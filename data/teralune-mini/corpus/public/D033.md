# Orbit 3 release notes

## Orbit 3.0 release

Orbit 3.0 was released on 2026-02-10. Its client prefix is /api/v3 and the measurement event is measurement.created. The token lifetime is 60 minutes. Clients that cache a 2.4 token for its old lifetime need to honor the expiry returned by the current token response.

Deploy API and event changes as separate checks. A successful API read does not validate a receiver subscription, and a received notification does not validate the sender's export scope. Keep a written cutover record for each integration.

## New defaults

The workspace budget is 1000 requests per minute. The general provisioning retention default is 90 days; plan settings can override that default. The webhook retry window is 72 hours.

A longer sender window increases the period during which an acknowledgment lost in transit can lead to a repeat. Review receiver persistence separately from the platform upgrade. An automatic workspace upgrade does not extend a local receiver cleanup job.

## Integration transition

The current connector is orbit-stream. The previous connector remains in its published transition period, but new deployments should use the current connector. Preserve old event envelopes in the integration archive until the rollback interval has closed.

After switching, observe one read, one write, one export and one callback. A transport-only health check of an HTTP endpoint would cover transport only; use an application-level observation for the actual workflow.
